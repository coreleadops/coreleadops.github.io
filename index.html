How it works

  1. We find the neglected ones. Widely-installed plugins with years of silence, unanswered support forums, and breakage on current WordPress and PHP.
  2. We rebuild them properly. Current WordPress APIs, current PHP (7.4–8.x), no dead bundled libraries, clean uninstall. No feature bloat — the utility you relied on, working again.
  3. You switch in minutes. Our plugins detect the abandoned original's settings and import them on activation. Deactivate the old one, activate ours, done.

Our commitments

Maintained, for real

Tested against current WordPress releases and PHP versions. Support threads get answered. If something breaks, it gets fixed — that's the whole business model.

Free core, forever

Everything the abandoned original did remains free. Paid tiers add genuinely new capabilities — never a ransom on features you already had.

Honest about what we know

We document our sources: version dates, support threads, and test results, with dates. When we report someone else's bug, we say "users report" until we've reproduced it ourselves.
